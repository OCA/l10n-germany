L10n DIN5008 Report Base
------------------------

This module provides the base functionality for configuring and
extending DIN 5008 report layouts in Odoo. It introduces a centralized
configuration dialog with a live report preview, allowing users to
configure DIN 5008 layout settings and identify the corresponding report
elements directly in the preview. A registry mechanism allows additional
modules to contribute their own configuration fields without modifying
the base configuration dialog.

Features
~~~~~~~~

-  Configure DIN 5008 report settings through the company document
   layout.
-  Display a live report preview in the configuration dialog.
-  Highlight corresponding report elements in the preview when selecting
   configuration fields.
-  Store all DIN 5008 settings in a centralized JSON field on the
   company.
-  Reset the configuration to its default values.
-  Store only values that differ from the default configuration.
-  Automatically apply default values for settings that have not been
   explicitly overridden.
-  Configure fold marks and punch/hole marks.
-  Configure company logo position, margins, and size, with different
   default sizes for DIN 5008 Type A and Type B.
-  Customize sender address formatting, including separators and
   spacing.
-  Configure country indicators for sender addresses.
-  Adjust sender and recipient address font scaling independently.
-  Separate sender and recipient address styling in DIN 5008 reports.
-  Configure the sender address left margin.
-  Configure the bottom page margin.
-  Support reusable configuration fields, including booleans,
   selections, numeric values, text, and lists.
-  Validate configuration values before applying changes.
-  Allow additional modules to register their own DIN 5008 settings
   without modifying the base configuration dialog.
-  Apply configured settings to DIN 5008 reports.

The configuration is stored in a single JSON field on the company, which
serves as the central source of truth for DIN 5008 settings. Default
values are generated from the registered configuration fields. Only
settings that differ from their defaults are stored as overrides. This
keeps the stored configuration compact and allows default values to
evolve with the module.

Users can reset the configuration to its default values. Resetting
clears the stored overrides, allowing the default configuration to take
effect again.

Additional modules can extend the configuration through the registry
mechanism. They can register module-specific settings, define their
types and default values, and specify preview selectors for highlighting
corresponding report elements. This approach keeps module-specific
settings separate while reusing the base configuration dialog, preview
functionality, and centralized storage.

Usage
=====

To configure the DIN 5008 report layout:

-  Make sure the correct company is selected. If necessary, switch to
   the company whose DIN 5008 report layout you want to configure.
-  Go to **Settings > General Settings** and select **Configure Document
   Layout** in the Company section.
-  Under **Document Layout**, select the **DIN 5008** report layout.
-  Select either **European DIN 5008 (A)** or **European DIN 5008 (B)**
   as the paper format.
-  Click **Configure parameters** to open the DIN 5008 configuration
   dialog.
-  Adjust the available settings in the respective sections. Use the
   live preview to identify report elements associated with
   configuration fields. Selecting a field highlights the corresponding
   element in the preview, where supported.
-  Click **Apply** to save your changes.
-  To discard custom settings and restore the default configuration, use
   the **Reset** option and confirm the action.
-  Generate a report using the DIN 5008 layout to verify the result.

**Note:** The configured settings apply only to reports that use the DIN
5008 external report layout and one of the supported European DIN 5008
paper formats (A or B).

**Preview limitations:** The live preview helps identify report elements
and review layout settings. The wizard preview and the generated
printout may differ slightly. Always use the generated report as the
reference for the final result.
