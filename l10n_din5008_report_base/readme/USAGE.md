To configure the DIN 5008 report layout:
* Make sure the correct company is selected. If necessary, switch to the company whose DIN 5008 report layout you want to configure.
* Go to **Settings > General Settings** and select **Configure Document Layout** in the Company section.
* Under **Document Layout**, select the **DIN 5008** report layout.
* Select either **European DIN 5008 (A)** or **European DIN 5008 (B)** as the paper format.
* Click **Configure parameters** to open the DIN 5008 configuration dialog.
* Adjust the available settings in the respective sections. Use the live preview to identify report elements associated with configuration fields. Selecting a field highlights the corresponding element in the preview, where supported.
* Click **Apply** to save your changes.
* To discard custom settings and restore the default configuration, use the **Reset** option and confirm the action.
* Generate a report using the DIN 5008 layout to verify the result.

**Note:** The configured settings apply only to reports that use the DIN 5008 external report layout and one of the supported European DIN 5008 paper formats (A or B).

**Preview limitations:** The live preview helps identify report elements and review layout settings. The wizard preview and the generated printout may differ slightly. Always use the generated report as the reference for the final result.
