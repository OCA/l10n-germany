To use this feature:
* Check that the correct company is currently selected. If necessary, switch to the company for which you want to configure the DIN 5008 representatives.
* Go to **Settings > General Settings** and select **Configure Document Layout** in the Company section.
* Under **Document Layout**, select the **DIN 5008** report layout.
* Enable or disable **Show representatives** as required.
* If enabled, review the configured company representatives and their roles in the Footer.
* Configure the representatives using the **res_company_representative** module if necessary.
* Generate a report using the DIN 5008 report layout.

The configured representatives are displayed in the **Legal** section of the DIN 5008 report, before the VAT identification number and other legal company information.

**Note:** The representative settings are only applied to reports using the DIN 5008 external report layout.

The way representatives are displayed depends on their assigned roles.
If all representatives have the same role, the role is displayed once followed by the representatives' names.
If representatives have different roles, the heading **Representatives** is displayed, followed by each representative's name and role.
