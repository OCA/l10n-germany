# Configuration

This module does not require additional configuration. The labor cost disclosure functionality works out of the box after installation.

## Product Setup

To mark a product as a labor cost product:

1. Navigate to **Products** → **Products**
2. Create a new product or edit an existing one
3. In the **General Information** tab, find the **§35a Labor Cost** section
4. Check the **Is Labor Cost Product** field

> **Note**: Only products of type "Service" can be marked as labor cost products. Products of type "Goods" or "Combo" are restricted by a validation constraint.

## No Additional Settings

There are no additional settings or configuration parameters to set. The module automatically:
- Calculates labor cost values on invoices
- Displays the disclosure notice when labor cost products are used
