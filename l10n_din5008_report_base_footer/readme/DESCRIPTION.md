## L10n DIN5008 Report Base Footer
This module extends the DIN 5008 report configuration with a customizable footer.

### Features
* Configure the footer line height and font scale factor.
* Adjust the spacing between the footer separator line and the footer content.
* Customize footer contact details and enable or disable the Font Awesome contact preset.
* Configure the footer table column widths.
* Choose whether to display one or up to two bank accounts in the report footer.
* Optionally display the bank account holder, company registration number, VAT ID, German tax number, and German business identification number (W-Id. No.).
* Select company contacts as representatives and optionally display them in the report footer.
* Translate contact job positions for multilingual reports.

**Note:** The footer settings apply to reports that use the DIN 5008 external report layout and one of the supported European DIN 5008 paper formats (A or B). The available settings depend on the installed DIN 5008 configuration modules.

The footer configuration extends the base DIN 5008 settings and uses the same centralized company configuration mechanism.
