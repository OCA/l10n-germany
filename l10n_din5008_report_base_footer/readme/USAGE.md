To configure the DIN 5008 report footer:
* Make sure the correct company is selected. If necessary, switch to the company whose DIN 5008 report footer you want to configure.
* Go to **Settings > General Settings** and select **Configure Document Layout** in the Company section.
* Under **Document Layout**, select the **DIN 5008** report layout.
* Select either **European DIN 5008 (A)** or **European DIN 5008 (B)** as the paper format.
* Click **Configure parameters** to open the DIN 5008 configuration dialog.
* In the **Footer** section, adjust the available settings as required, including line height, spacing to the separator line, font scale factor, contact details, table column widths, and optional company information.
* Configure whether to display one or up to two bank accounts in the footer.
* If required, enable the display of representatives and select the relevant company contacts. Make sure their job titles are configured and provide the corresponding translations if reports are generated in multiple languages.
* Click **Apply** to save your changes.
* Generate a report using the DIN 5008 report layout to verify the result.

**Note:** The configured footer settings apply only to reports that use the DIN 5008 external report layout and one of the supported European DIN 5008 paper formats (A or B).

**Preview limitations:** The wizard preview and the generated printout may differ slightly. Always use the generated report as the reference for the final result.
