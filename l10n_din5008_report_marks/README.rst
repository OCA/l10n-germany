L10n DIN5008 Report Marks
-------------------------

This module adds configurable DIN 5008 fold and punch/hole marks to
reports using the DIN 5008 report layout.

The marks can be enabled or disabled independently per company and are
displayed in the document layout preview and rendered in the final PDF
reports.

Usage
=====

To use this feature:

-  Check that the correct company is currently selected. If necessary,
   switch to the company for which you want to configure the DIN 5008
   marks.
-  Go to Settings > General Settings and select Configure Document
   Layout in the Company section.
-  Under Document Layout, select the DIN 5008 report layout
-  Enable or disable the Fold marker and Punch/Hole marker options as
   required.
-  Generate a report using the DIN 5008 report layout.

Note: To display the DIN 5008 marks, the paper format must be set to
either European A4 for DIN 5008 Type A or European A4 for DIN 5008 Type
B.

The wizard preview and the generated printout may differ slightly.
Always use the generated report as the reference for the final result.
