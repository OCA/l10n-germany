To use this module:

1. Install module *l10n_de_tax_statement*.
2. Install module *l10n_de_tax_statement_elster*.
3. Configure the German tax number (Steuernummer) in the company
   settings (field: *l10n_de_stnr* from Odoo core l10n_de module).

**Technical notes:**

- The XML follows the format documented at
  ``https://www.elster.de/eportal/helpGlobal?themaGlobal=ustva_upload``
- Schema namespace: ``http://finkonsens.de/elster/elsteranmeldung/ustva/v2026``
- Schema version: ``2026``
- Character encoding: ``ISO-8859-15``
