To export a VAT statement as ELSTER XML:

1. Open a posted VAT statement (version "2026") in Odoo.
2. Click the **ELSTER XML herunterladen** button.
3. Save the generated XML file.

The XML file can then be imported into Mein ELSTER:

1. Log in to www.elster.de (Mein ELSTER).
2. Open the "Umsatzsteuer-Voranmeldung 2026" form.
3. Choose "Formulardaten hochladen".
4. Select the downloaded XML file.
5. Verify the imported values.
6. Submit the form manually.

**Important:** The values must be verified in Mein ELSTER before
submission. This module provides a data import helper only.
The actual tax declaration must be submitted manually through
Mein ELSTER.
