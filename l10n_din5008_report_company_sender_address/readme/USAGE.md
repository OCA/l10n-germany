To use this feature:
* Check that the correct company is currently selected. If necessary, switch to the company for which you want to configure the DIN 5008 sender address.
* Go to Settings > General Settings and select Configure Document Layout in the Company section.
* Under Document Layout, select the DIN 5008 report layout.
* Configure the desired Country Indicator and Address Separator.
* Set the desired Font Size Scale Factor for the company sender address. The value must be between 0.5 and 1.5.
* Generate a report using the DIN 5008 report layout and verify the resulting company sender address.

**Note: The configured sender address may slightly differ from the document layout wizard preview. Always use the
generated report as the reference for the final result.**
