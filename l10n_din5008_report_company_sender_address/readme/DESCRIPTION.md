## L10n DIN5008 Report Company Sender Address

This module extends the DIN 5008 external report layout with configurable options for the company sender address.

The standard DIN 5008 sender address may not provide sufficient flexibility for different company layouts and
addressing requirements. This module allows the company sender address to be customized while preserving the
DIN 5008 report layout.

Features:
* Configure the country indicator displayed in the company sender address.
* Choose between the country code and country name, or hide the country indicator.
* Configure the separator used between individual address components.
* Choose between a pipe (`|`) and a dot (`•`) as the address separator.
* Configure the font size scale factor for the company sender address.
* Restrict the sender address font scale factor to a valid range of 0.5 to 1.5.
* Apply the configured settings to reports using the DIN 5008 external report layout.

The settings are available in the company document layout configuration and apply to reports using the
DIN 5008 external report layout.
