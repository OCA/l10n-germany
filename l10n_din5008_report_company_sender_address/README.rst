L10n DIN5008 Report Company Sender Address
------------------------------------------

This module extends the DIN 5008 external report layout with
configurable options for the company sender address.

The standard DIN 5008 sender address may not provide sufficient
flexibility for different company layouts and addressing requirements.
This module allows the company sender address to be customized while
preserving the DIN 5008 report layout.

Features:

-  Configure the country indicator displayed in the company sender
   address.
-  Choose between the country code and country name, or hide the country
   indicator.
-  Configure the separator used between individual address components.
-  Choose between a pipe (``|``) and a dot (``•``) as the address
   separator.
-  Configure the font size scale factor for the company sender address.
-  Restrict the sender address font scale factor to a valid range of 0.5
   to 1.5.
-  Apply the configured settings to reports using the DIN 5008 external
   report layout.

The settings are available in the company document layout configuration
and apply to reports using the DIN 5008 external report layout.

Usage
=====

To use this feature:

-  Check that the correct company is currently selected. If necessary,
   switch to the company for which you want to configure the DIN 5008
   sender address.
-  Go to Settings > General Settings and select Configure Document
   Layout in the Company section.
-  Under Document Layout, select the DIN 5008 report layout.
-  Configure the desired Country Indicator and Address Separator.
-  Set the desired Font Size Scale Factor for the company sender
   address. The value must be between 0.5 and 1.5.
-  Generate a report using the DIN 5008 report layout and verify the
   resulting company sender address.

**Note: The configured sender address may slightly differ from the
document layout wizard preview. Always use the generated report as the
reference for the final result.**
