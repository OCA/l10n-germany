To use this feature:
* Check that the correct company is currently selected. If necessary, switch to the company for which you want to configure the DIN 5008 bottom margin.
* Go to Settings > General Settings and select Configure Document Layout in the Company section.
* Under Document Layout, select the DIN 5008 report layout.
* Set the desired Bottom Margin value in millimeters.
* Generate a report using the DIN 5008 report layout and verify the resulting page layout.

**Note: The configured bottom margin is not reflected in the document layout wizard preview. The preview does not
accurately represent the final PDF layout in this regard. Always use the generated report as the reference
for the final result.**
