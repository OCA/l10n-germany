Odoo DATEV API
--------------

The datev_api module allows you connect your Odoo to the DATEV API and
the offered services. It implements the OAuth authentication and access
token handling. The additional services are connected through additional
modules building on top of this.

Known issues / Roadmap
======================

- Implement modules to interact with the different services

  - Module to export DTVF from ``datev_export_dtvf`` to
    ``accounting:extf-files``
  - Module to export XML from ``datev_export_xml`` to
    ``accounting:dxso-jobs``

    - This requires the `ledger XML
      format <https://developer.datev.de/de/file-format/details/datev-xml-interface-online/format-specification->`__
