Report Footer (Germany)

This module is the common base for the German report footer. It provides the company footer configuration that report layouts share, so that the standard Odoo layouts, the DIN 5008 layout shipped with Odoo (l10n_din5008, through l10n_din5008_footer) and layout_din5008 print the same footer content.

  • Company placeholders: the footer text, the address and the tagline of the document layout can contain company data (phone, e-mail, VAT, bank account, …) inserted with the dynamic placeholder picker of the HTML editor (type / in the editor). The placeholders are rendered when a report is printed. With the module html_editor_icon (OCA/web) installed, the same texts offer an /icon command to insert Font Awesome pictograms, for example in front of the phone number or the e-mail address.
  • Footer lines: a shared QWeb hook (l10n_de_report_footer.footer_lines) in the company address block of every layout. Modules such as l10n_de_report_footer_representative add lines (representatives, register court, …) once and they appear in every layout.
  • Layout settings: the settings of the document layout are stored in one JSON field of the company. Modules declare their settings in Python (key, type, default, range, section) and the document layout wizard renders them in tabs, with a live preview, without an own field or view per setting.
  • Bottom margin: the bottom page margin of PDF reports can be increased in the document layout when the footer needs more space than the paper format reserves (previously the module l10n_din5008_report_margin_bottom).
  • Preview highlight: while a field of the document layout that changes a size or a margin is focused, the affected area is outlined in the preview.

Configuration

Go to Settings > Companies > Configure Document Layout.

  • Address, Tagline and Footer: write the texts. Type / or use the placeholder button of the editor to insert company data, for example the phone number, the VAT number or a bank account. Placeholders on the usual company fields (address, phone, e-mail, website, VAT, company registry, …) can be used by everyone; other expressions are reserved to administrators and members of the Mail Template Editor group, like in mail templates.
  • Bottom Margin (mm) (tab Page of the layout settings below the paper format): bottom page margin reserved for the footer, between 5 and 60 mm. 0 keeps the margin of the paper format. Clear the field to restore the default.

While the bottom margin field is focused, the footer area is outlined in the preview.

Usage

Print any report using a document layout. The footer text is printed with the placeholders replaced by the data of the company that issues the document, followed by the footer lines added by other modules.

Developers: call <t t-call="l10n_de_report_footer.footer_lines"/> inside a <ul> of a custom layout and add <li> elements to the hook //t[@name='l10n_de_report_footer_lines'] of that template to print additional lines in every layout. Give a form field the class o_report_preview_highlight_<key> and style html[data-report-preview-highlight="<key>"] <selector> in the report assets to outline an area of the layout preview while the field is focused.

Developers: register a layout setting instead of adding a field to the company and to the wizard. Inherit the mixin report.layout.config.mixin and append the declaration to _get_report_layout_config_fields():

class ReportLayoutConfigMixin(models.AbstractModel):
    _inherit = "report.layout.config.mixin"

    def _get_report_layout_config_fields(self):
        return super()._get_report_layout_config_fields() + [
            {
                "key": "my_module.show_bank",
                "label": self.env._("Print Bank Account"),
                "section": "my_module",
                "section_label": self.env._("My Layout"),
                "section_sequence": 50,
                "type": "boolean",
                "default": True,
                # optional: "min", "max", "step", "allow_zero" (numbers),
                # "options": [(value, label), ...] (selection), "help",
                # "highlight": "footer", "visible_if": {"other.key": True},
                # "layouts": ["my_module.external_layout_x"]
            }
        ]

The value is stored in the JSON field report_layout_config of the company under its key and validated against the declaration when the company is written. Read it in templates and code with company._get_report_layout_config_value("my_module.show_bank"), which returns the declared default while nothing is stored. The wizard offers the setting on the tab of its section for the layouts listed in layouts (all layouts when absent).
